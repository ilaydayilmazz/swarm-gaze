# Experiments

Earlier studies on the way to Through Time. Kept for the record; not needed to run the main project.

| File | Study | What it tried |
| --- | --- | --- |
| `index.html` | Swarm Gaze (browser) | A swarm's attention on one image, as flowing pigment |
| `docs/` | Swarm Gaze results | Attention and pigment on my drawing |
| `bee_gaze.py`, `bee_gaze_colab.ipynb` | Bee Gaze | Learn one artist's marks; an artificial bee colony paints with them |
| `machine_feels.py` | Machine Feels | Guess a feeling with a starter rule (not human data); a flock of birds draws it |
| `carried.html` | Carried | A person's gesture, and a shared memory of everyone's gestures, move the light |
